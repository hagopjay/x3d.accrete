## Strengths the reviewers could not break

- [gate] Forbidden tags and fields are rejected whatever the case: 'box'/'Size' variants fail NODE_FORBIDDEN or FIELD_FORBIDDEN. A wrapped <Fragment> inside the input is rejected. Probe: p1.py and the fuzz harness.
- [gate] XML preflight holds. The DOCTYPE/ENTITY/CDATA/comment/PI/'<!' checks, the entity regex and numeric char refs, duplicate attributes (an ET.ParseError), and namespaced tags/attributes (turned into {uri}name and refused) all failed closed. A stray xmlns:* attribute is dropped silently and does not appear in the output. This was checked by reading the code and by p1.py/fz.py.
- [gate] 30,000 mutation-fuzz runs (fz.py: nan/inf/1e999/1e-400/empty/unicode/truncation applied to attributes of two rich fragments) produced zero uncaught exceptions. Every result was a normal dict with pass or a GATE_* error.
- [gate] DEF/USE: forward USE, type-mismatched USE, USE with fields/children, self-containing USE (ancestor check), duplicate DEF, and empty or non-ASCII DEF names are all refused. USE expansion is counted through the DEF cache: 160 expanded shapes and 1 expanded light are enforced, and the 128-instance doubling chain was rejected at 256.
- [gate] ROUTE graph: only TimeSensor.fraction_changed to Interpolator.set_fraction, and Interpolator.value_changed to typed Transform/Material/Light targets. Interpolator-to-interpolator chains, wrong types and non-top-level ROUTEs fail. Light intensity animation outside [0,1] is refused.
- [gate] Animated-bounds envelope reasoned sound: routed translation/center/scale samples are folded into the t + c + s*(r+c) bound; rotation and scaleOrientation cannot enlarge a sphere bound; USE reuse is bounded by the per-node cache; overflow becomes BOUNDS_NONFINITE.
- [gate] Index handling holds: indices below -1, indices at or above the point count, empty or short faces, and Color arrays that are too short are all refused. ElevationGrid height count equals xDimension*zDimension.
- [gate] Canonical output is deterministic. Attributes are sorted, floats use repr, -0 becomes '0', and 1.0/1 spellings collapse to one output. Light global is forced to false even if the input says true. The unit suite passes 85/85, matching VALIDATION.md.
- [ledger] Hash chain and per-field tamper detection. Probe: tamper.py mutated 17 fields on entry 4 of examples/world.json. All were caught as ENTRY_MISMATCH: raw, canonical and scene bytes, hash, item and payload created_utc, plan.seed_word, title, instruction, generation, tier, attempt_id, mcp.instrument.commit, xsd findings, render status, pipeline.files. The checkpoint hash tamper is caught as CHECKPOINT_HEADER_MISMATCH. Swapping entries, duplicating an entry, and truncation with an externally held --checkpoint are all caught.
- [ledger] Compare-and-swap head/tail under contention. Probe: t2.py ran 6 threads appending at the same expected_head=0 and tail. Exactly 1 succeeded and 5 raised Conflict. Verify stayed valid, and 6 attempt rows were recorded (1 committed, 5 conflicts).
- [ledger] The 10,000 cap is enforced and is only a configured bound. Probe: t2.py with max_entries=3 refused the 4th append with the 'configured entry cap' ValueError. expected_head above the cap is also refused. The cap is a per-process constructor argument and is not stored in the DB.
- [ledger] Placement replay is deterministic and collision-free. Probe: replaying plan_next 10,000 times gave 0 duplicate (cell, level) pairs and max level 5. Verify rejects a modified plan (tamper.py).
- [ledger] Merged .x3d export preserves DEF/ROUTE isolation. Probe: t2.py exported a world with two patches. The DEF names carry per-entry prefixes such as A000001_Clock, the ROUTEs refer only to prefixed nodes, and there were 0 duplicate DEFs. The merged scene passed the pinned XSD and semantic validate_scene. t3.py confirmed the gate refuses top-level ROUTE, cross-patch USE (GATE_USE_FORWARD), and ROUTE inside Group. A DEF named like another patch's prefix is double-prefixed (A000002_A000001_Rotor), so there is no collision.
- [ledger] Canonical JSON rejects bad input. Probe: strict_json refuses NaN, Infinity and duplicate keys. canonical rejects inf with ValueError. Unicode is emitted as raw UTF-8. Key order is sorted. Integral floats normalize (1.0 equals 1, -0.0 becomes 0, 1e22 becomes an int).

## Notes
- F1: PhysicalMaterial is in the documented gate vocabulary but the pinned semantic check rejects it under the Immersive wrapper, so it can never be admitted. Documented here; vocabulary unchanged pending a decision (wrapper `<component name="Shape" level="2"/>` or drop the node).
- L1: verify_archive checks self-consistency, not that a forged entry passed the gate. Use an external checkpoint. The browser verifier has the same scope and says so.
- L3: append cost is dominated by repeated payload JSON parses (confirmed at ~100 entries); plan-index columns are the proposed fix, not yet built.
- C1: benchmark sizes/hashes are single-run, rig-specific; only timings reproduce (within ~5%).
- F2/F3: only validation, validation.validate and validation.semantic are origin-checked; other vendored submodules are hash-listed but not origin-asserted at import.
